# Roots 1.0.0 Release Notes

Welcome to the first public release of Roots.

- Scan packaged-food barcodes.
- Photograph ingredient labels for extraction and review.
- Create a personalized dietary profile.
- Understand ingredient-level Safe, Caution, and Avoid reasons.
- Find restaurants and review available menu evidence.
- Analyze dishes and build an order from menu-supported options.
- Ask food questions, adapt recipes, and explore meal ideas.
- Prepare translated dining cards and questions with Travel Mode.
- Save products, meals, and useful reports.
- Access profiles, history, Saved information, cached products, and prepared travel content offline where supported.

Roots explains the evidence it has and flags uncertainty instead of guessing. AI features can explain or transform information but never override deterministic compatibility results.

Release note status: copy draft only. The repository currently identifies its package version as 2.0.0, so the intended public version must be reconciled before using these 1.0.0 notes.
